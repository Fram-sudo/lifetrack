# ⚙ Configuration Lifetrack

## Clé API TMDB

Remplis `tmdb_api_key` ci-dessus pour activer l'auto-remplissage des fiches **Films** et **Séries** depuis TMDB/IMDb (titre, année, genres, covers, bannière, réalisateur, synopsis...).

Clé gratuite (2 min) : https://www.themoviedb.org/settings/api → "API Read Access Token" ou "API Key (v3 auth)"

> Les **Animés** utilisent **AniList** (gratuit, aucune clé requise).

Ce fichier n'est **jamais écrasé** par le script de mise à jour : ta clé reste privée et locale.
